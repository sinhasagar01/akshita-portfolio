⚠ The row is a grid with explicit tracks, not nested flex

The first attempt nested three flex contexts — row, right-hand group, reorder cluster — and the cluster stretched to fill the row, squeezing the title onto two lines and truncating the summary to one word. Adding flex: 0 0 auto at each level did not fix it, because the fragility was the structure rather than any one declaration. The row is now one grid, seven tracks: six auto and one 1fr. Every element is either its content width or the single flexible column. There is no second place for space to go. This is #178's w-0 computing to 264px, learned properly — a correct class string is not a correct layout, and the answer is to state the box rather than keep adding declarations that ask for it.

Two defects this fixes

boAt Crest reads as disabled today — its row is dimmed because it is bespoke, but bespoke is not disabled: title, hero, summary and platform are all editable and only the body is in code. That is hazard 29's shape one screen earlier, and here it is a chip at full text strength. And "0 sections" becomes "No sections" — a zero beside three fifteens reads as a study that lost its content.

Why the ordinal leads

The page's own subhead says the arrows set the homepage order, and nothing on the page believed it. The ordinal is the first thing read, with a drag handle beside it and the arrows kept as the keyboard path — this project has no drag anywhere yet, so if drag is deferred the list still works.

▲ / ▼ here, ← / → in Grid

One column has no wrap, so up and down mean exactly what they say. A grid wraps, so the study before a row's first card is visually to its left. That asymmetry is each control matching its own layout, not an inconsistency.

The row cannot be a button element

It is clickable and it contains buttons. A button inside a button is an invalid content model — #176's finding on a new surface. So it is a div with role="button" and tabindex, stopPropagation on the inner controls, and an authored focus ring, since a role-button div gets no ring and no Space/Enter for free.
