The problem

Faux body copy so the rail has a real page to sit against. Scroll down: the rail is hidden here, because the sentinel below the first section has not been passed yet.

Everything above this point is the reader's first impression. Introducing a persistent control before they have read anything competes with the hero for attention and reads as chrome.

Rail hidden above this line

Approach

Rail shown from here

The sentinel just above has left the viewport, so the rail slides up. From this point on it stays available for the whole read — no scroll listener, one IntersectionObserver.

Keep scrolling into the pinned section below to check the rail over a scroll-story block, then all the way to the footer to see it retract.

Pinned scroll section

The rail overlaps this by design — eyeball it here.

Outcome

Last body section. The footer is next; watch the rail retract as it enters view, so the footer's own links are never covered.
