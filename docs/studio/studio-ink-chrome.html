AI first is a research posture, not a feature

Most AI features are a second route to a screen that already existed.

the figure, unchanged

The pattern is easy to recognise once you have shipped it. A product exists, a model becomes available, and somebody adds a box in the corner where the user can type a question. The box is real work. It ships. It demos well.

Then you watch the analytics and almost nobody opens it, and the people who do ask it to describe the screen they are already looking at.
