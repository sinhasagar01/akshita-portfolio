What this shape costs

Two things a mockup cannot show. The panel floats inside a pane that is overflow-y-auto, so for the last field in a section it will clip at the pane's edge — and hazard 2 records that StudioModal has no portal, so there is nothing existing to reuse. And the motion needs the reduced-motion path, which is the toggle above.

Three things the native select gave free. Keyboard (arrows, Home, End, Escape, type-ahead), screen reader (role, state, count, active descendant), and a focus ring the platform managed. All three are now the component's to write and to prove.

The check rather than the 3px bar is deliberate. #209's selection language marks a persistent selection in a list you navigate. A dropdown option is a transient choice in a list you dismiss — using the bar would make one mark mean two kinds of thing.
