Both drop the uppercase and the eyebrow tracking, lead with a bolded Live preview. so the line has an entry point, and set **bold** in mono so it reads as syntax to type rather than as emphasis.

One structural note either way. imageBusy and imageError currently render inside this same container and reset normal-case tracking-normal to escape its styling. Those are transient upload status, not part of the hint — if they stay inside a framed strip, an upload error appears to be part of the instructions. Both variations move them to their own line below, where the error can also take a proper role="status".
