What this file is authoritative about: the composition, the panel order, the copy block carrying its contrast report as comments, the token grid, the sticky preview and the OKLCH band. What it is not: the token values, which approximate the site's roles so it renders standalone, and the compatibility dots, which are hardcoded here and must be computed at build.


Tool-shaped, and the preview never leaves the screen — the panel scrolls past a sticky render, so a copy or a contrast reading is always next to the thing it describes. Cost: the page has one screen and a footer; there is no reading order to speak of, and it asks the visitor to explore rather than telling them anything.



⚠ Three decisions still open, and all three are mechanism rather than styling. Whether Try across portfolio survives navigation — the spec says temporary, so it is a cookie or a session flag with a visible way back, not a class swap. Whether compatibility is computed from the tokens at build or listed per palette; only the first stays true when a palette is retuned. And whether the preview imports the real components — a facsimile drifts, and this page's whole claim is that the system is real.
